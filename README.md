<h1>Funding System</h1>
<h2>About</h2>
<p>This is a property financing system that, by entering the property value, annual interest rate, and financing term, calculates the total financing amount based on the defined business rules. Additionally, the system sums the total value of the properties added, showing the consolidated amount of all financings</p>
